# P1Label 设计规格 v2（视觉 + 交互全面重做）

> 状态：**草案**（待评审后实施）
> 范围：主窗口视觉语言、信息架构、编辑器交互全面重做。
> 红线：`LPAPI` / `P1USB` / `P1BLE` / `LabelRenderer.pagePayload` 的字节流行为
> **不动**；`LabelCanvas` 的"单一静态手势面"拖拽架构**不动**（见
> `LabelCanvas.swift` 头注释与 `AGENTS.md` 坑 1）。

---

## 1. 背景与目标

当前主窗口在 #7 中按 pagx 设计稿重构过：左侧 360pt 设置侧栏（五张卡片）+
右侧画布区。视觉上是干净的，但经过使用暴露出三类问题：

1. **编辑器能力弱**：单选、无撤销/重做、无复制粘贴、无键盘微调、无图层列表。
   元素一多（>5 个）排版效率断崖式下降。
2. **自绘控件面过大**：红绿灯、滑杆、步进器、菜单、分段控件全部手绘
   （`MainWindow.swift` 里约一半代码是控件复刻），维护成本高，且自绘红绿灯
   已知脆弱（代码注释里记录了 ghosting 问题）。
3. **预览 ≠ 打印**：画布预览用 SwiftUI `Text`，打印用 CoreText（坑 3），
   CJK 长文换行点可能出现差异。

### 本轮目标

| # | 目标 | 判定标准 |
|---|------|----------|
| G1 | 视觉全面刷新：新布局 + 新视觉语言，明显区别于 v1 | 并排截图对比，布局结构、配色、控件均不同 |
| G2 | 编辑器达到"可日常使用"的底线：撤销、多选、复制、键盘、图层列表 | 每项有对应快捷键与入口，验收清单（§9）全过 |
| G3 | 自绘控件面缩小 ≥60%：优先用系统控件 + 少量精修 | `MainWindow.swift` 中自定义控件结构体数量对比 |
| G4 | 预览与打印同一排版引擎 | CJK 长文、中英混排、自动换行 3 组样张，预览位图与打印扫描件逐元素对位 |

### 非目标（本轮不做）

- 多文档/多窗口（仍为单文档 + UserDefaults 持久化）
- 深色模式（热敏输出是黑底白纸，深色预览反而失真；维持浅色固定）
- 图片元素、表格元素（列为后续候选，见 §8）
- 打印参数新增项、纸张预设新增项（硬件校准流程不变）

## 2. 信息架构：新主窗口布局

### 2.1 布局总览

```
┌──────────────────────────────────────────────────────────────┐
│  ⛔️🔴🟡🟢   P1Label          [模板] [纸张 ▾]        ⚙️ 设备   │ ← 顶栏 48pt
├──────────────────────────────────────────────┬───────────────┤
│  ＋文字 ＋二维码 ＋条码 │ ↩︎ ↪︎ │ 🗑 复制 │ 缩放 ▾   │               │
│──────────────────────────────────────────────│  属性检查器    │
│                                              │  (右侧 280pt)  │
│                画布区（纸张居中）              │  ──────────   │
│                                              │  · 所选元素    │
│                                              │  · 无选择时    │
│                                              │    显示文档/纸张│
│──────────────────────────────────────────────│               │
│  状态条：设备 ● 已连接 · 40×30 模切 · 3 个元素 │  [打 印]      │
└──────────────────────────────────────────────┴───────────────┘
```

与 v1 的关键差异：

| 变化 | v1 | v2 | 理由 |
|------|----|----|------|
| 属性面板位置 | 左侧 360pt 常驻 | **右侧 280pt，上下文相关** | macOS 编辑器惯例（Keynote/Pages/Sketch）；左侧放"添加/操作"动作，右侧放"所选对象"属性，动作与属性分离 |
| 添加元素入口 | 侧栏一张卡片 | **顶栏工具条** | 高频操作上移；添加后元素出现在画布中心，右手操作面板、左手画布动线更顺 |
| 设备状态 | 侧栏第一张卡片 | **底栏左端状态区 + 顶栏 ⚙️ 弹出设置** | 设备是低频配置、高频确认——降级为状态显示，详情收进弹出面板 |
| 打印按钮 | 画布右下角 | **右栏底部主按钮**（常驻可见） | 与属性面板同侧，打印前最后看的正是打印参数 |
| 纸张设置 | 侧栏卡片 | **顶栏「纸张」弹出 popover** | 换纸是低频操作；当前纸张名常显在顶栏，一眼可确认 |
| 窗口红绿灯 | 自绘 + 隐藏系统灯 | **恢复系统红绿灯**，叠在顶栏上（`.fullSizeContentView`） | 删除 `TitleBarDragView` / `TrafficLights` 两个最脆弱的组件（G3） |

### 2.2 窗口规格

- 最小尺寸 1080×700（沿用），默认 1280×800。
- 顶栏 48pt；右栏 280pt（允许用户拖拽分割线在 240–340 间调整，记住位置）；
  底部状态条 32pt；其余为画布。
- 画布区背景为中性灰，纸张带投影居中；纸张随窗口尺寸自动"适应"缩放。

## 3. 视觉语言

### 3.1 设计原则

1. **系统优先**：控件一律优先 `SwiftUI` 原生（`.rounded` bordered button、
   原生 `Stepper`/`Slider`/`Picker`/`Toggle`），只在画布选区、进度等少数处精修。
   自绘仅保留：`HSlider`（若原生观感不可接受）与画布覆盖层。
2. **黑白灰为骨，单一强调色为魂**：热敏标签本身就是黑白产物，编辑器用
   近乎单色的界面突出纸张内容；强调色只用于选中态、主按钮、进度。
3. **纸张即主角**：画布区一切元素（背景、网格、标尺）都不与纸张争夺注意力。

### 3.2 Design Tokens（v2 全量替换 `Design` enum）

| Token | 值 | 用途 |
|-------|----|-----|
| `accent` | `#4C6FFF` | 选中框、主按钮、进度、焦点 |
| `accentSubtle` | `#EEF1FF` | 主按钮 hover、添加按钮底色 |
| `bg.window` | `#F2F2F4` | 窗口底（近 NSWindow systemGray6） |
| `bg.sidebar` | `#FFFFFF` | 右栏/顶栏/底栏 |
| `bg.canvas` | `#E4E5E9` | 画布区背景 |
| `bg.canvasGrid` | `black @ 4%` | 画布 8pt 网格点阵（可关） |
| `text.primary` | `#1C1C1E` | 一级文字 |
| `text.secondary` | `#6C6C70` | 二级文字、标签 |
| `text.tertiary` | `#9A9AA0` | 占位、禁用 |
| `stroke.hairline` | `black @ 8%` | 分隔线、控件描边 |
| `stroke.focus` | `accent` | 焦点环（用系统 `.focusable`/focus ring 优先） |
| `state.ok` | `#34C759` | 设备已连接 |
| `state.warn` | `#FF9F0A` | 未验证纸张提示 |
| `state.error` | `#FF3B30` | 连接失败、打印失败 |
| `guide.snap` | `#FF2D92` | 吸附对齐线（沿用现有粉色语义） |
| `radius.control` | `6` | 按钮/输入框圆角 |
| `radius.panel` | `10` | 卡片、popover 圆角 |
| `radius.paper` | `2` | 纸张圆角（更接近实物直角） |
| `spacing.unit` | `4` | 全部间距为 4 的倍数（4/8/12/16/24） |
| `font.body` | system 12 | 正文、标签 |
| `font.caption` | system 11 | 辅助说明 |
| `font.title` | system 13, semibold | 面板标题、按钮主文案 |

阴影只有两档：`shadow.card`（黑 6%，r=4, y=1）与 `shadow.paper`
（黑 18%，r=12, y=4）。其余一律描边。

> 迁移说明：v1 的 `Design` enum 整体删除，全部引用点改为新 token；不允许
> 新代码里出现裸 `Color(red:green:blue:)`。

### 3.3 字体

界面字体 = 系统字体（SF Pro），中文随系统回退。**元素文本渲染字体不变**
（打印路径 `measureText` 用 CoreText，见 §6.5）。

## 4. 组件规格（自绘 → 系统映射）

| v1 自绘组件 | v2 方案 |
|-------------|---------|
| `TrafficLights` + `TitleBarDragView` | 删除。`.fullSizeContentView` + 系统红绿灯，顶栏左侧留 70pt 空位 |
| `HSlider` | 原生 `Slider`（`.tint(accent)`）；仅画布缩放条若视觉不合再精修 |
| `StepperField` | 原生 `Stepper` + `TextField` 组合，或 `LabeledContent` 行 |
| `MenuField` | 原生 `Picker(.menu)` |
| `Segmented` | 原生 `Picker(.segmented)` |
| `PositionField` | 保留（字符串回显逻辑有坑记录，整体搬入新 Inspector） |
| `smallButtonLabel` / `card()` | 删除，用系统 `.buttonStyle(.bordered/.borderedProminent)` |
| 画布选区框/删除钮/对齐线 | **保留自绘**（这是画布覆盖层，系统控件做不了） |

每个组件给出明确规格（尺寸、状态、动效）：

- **按钮**：高度 28pt（普通）/ 32pt（主按钮「打印」）；主按钮 = accent 填充
  白字；打印中变为「发送中…」+ 内联进度，禁用态 40% 透明。
- **输入框**：高度 28pt，`radius.control`，hairline 描边，聚焦时 accent 描边。
- **顶栏工具条按钮**：36×36 图标按钮，hover 时 `bg.window` 圆角 6。
- **Popover**（纸张/设备/模板）：宽 308pt，`radius.panel`，白底 + hairline
  描边 + 双层投影（near: 黑 8% r6 y2；far: 黑 12% r24 y-4 spread-4），
  内边距 14 / 行距 10；结构 = 标题行（13 Semibold）+ 表单行。
  设计稿见「设备 popover ×2 / 纸张 popover ×2」画板。

## 5. 交互设计：编辑器能力（G2 核心）

### 5.1 选择与命中

| 操作 | 行为 |
|------|------|
| 单击元素 | 选中（替换现选区） |
| ⇧ 单击 | 加入/移出多选 |
| 空白处拖拽 | 框选（marquee，虚线矩形 + 半透明填充） |
| 空白处单击 | 清空选区 |
| Tab / ⇧Tab | 按 z 序切换选中元素 |
| Esc | 多选 → 单选（最后一个）→ 清空 |

多选时 Inspector 顶部显示「已选中 N 个元素」，仅显示共有属性（对齐/分布、
删除）；属性编辑仅在单选时可用。

### 5.2 键盘

| 键 | 行为 |
|----|------|
| 方向键 | 移动 1 dot（= 1 点阵像素，文档单位） |
| ⇧ + 方向键 | 移动 8 dots |
| ⌫ | 删除所选（带确认的删除钮逻辑保留给画布 × 按钮；键盘删除走撤销，不弹确认） |
| ⌘Z / ⇧⌘Z | 撤销 / 重做 |
| ⌘C / ⌘V / ⌘D | 复制 / 粘贴（原位 +8,+8 偏移）/ 复制一份 |
| ⌘A | 全选 |
| ⌘= / ⌘- / ⌘0 | 放大 / 缩小 / 适应窗口（100% = 1 dot = 1pt） |
| Enter（文本元素） | 进入画布内联编辑（§5.5） |

快捷键通过 SwiftUI `.keyboardShortcut` + `Edit menu commands` 实现；
**全部键盘编辑必须走同一个 `commit` 路径进撤销栈**。

### 5.3 撤销/重做（新基础设施）

- `PrintModel` 增加 `HistoryStack`：快照式（`LabelDocument` 整体 + 选区），
  深拷贝入栈。文档规模（<100 元素、纯值类型）下快照成本可忽略，不做增量 diff。
- **写入口收敛**：拖拽/缩放手势在 `commit` 一次写入（现状已如此）；Inspector
  控件、键盘操作、删除、粘贴全部经由新增的 `mutate(_ body: (inout LabelDocument) -> Void)`。
  排除 `schedulePersist` 之类的副作用写入。
- 拖拽过程中不逐帧入栈：手势开始时记 `beginGestureSnapshot`，`commit` 时若有
  位移才落一条。
- 栈深 100；跨「纸张尺寸变更」的撤销允许（元素钳制逻辑是幂等纯函数）。

### 5.4 对齐与分布（多选工具）

单选时：Inspector 显示「与纸张对齐」九宫格按钮（水平居中/垂直居中/贴边×4）。
多选（≥2）时：显示对齐 6 键（左/水平中/右/上/垂直中/下）与分布 2 键
（水平/垂直等距，≥3 个元素）。全部走 `mutate` 入撤销栈。

### 5.5 画布内联文本编辑

双击文本元素 → 元素原位出现 `TextField`（CoreText 同款字体的 SwiftUI 覆盖层，
仅编辑期），失焦或 Enter 提交、Esc 取消。这是"预览≠打印"问题的治本方案之一
（§6.5 配套）。实现要点：内联编辑框挂在 `selectionControls` 层之上，
**不得引入第二个手势面**——编辑态临时禁用画布手势。

### 5.6 图层列表（右栏底部，可折叠）

按 z 序（顶部在前）列出元素：类型图标 + 内容摘要（文本前 8 字 / "二维码"）。
拖拽行 = 改 z 序；单击 = 选中并滚动画布到该元素；hover 显隐眼睛图标 =
`hidden` 属性（新字段，见 §7）。隐藏元素不参与打印与命中测试。

### 5.7 画布缩放与平移

- 保留双指捏合；补齐 ⌘滚轮缩放（以光标为锚点）、空格拖拽平移。
- 工具条缩放控件（设计稿定稿样式）：**「− / 100% / ＋」三段式步进器**，
  一个圆角容器内以分段 hairline 分隔；`⌘=`/`⌘-` 映射 ＋/− 按钮，
  `50% · 200% · 适应窗口` 收在倍率段的上下文菜单（长按/右键），不占默认视觉。
- 缩放/平移是视图状态（`@State`），**不进撤销栈、不进文档**。

## 6. 各区域详细规格

### 6.1 顶栏（48pt）

从左到右：系统红绿灯占位 → App 标题（13 semibold）→ 工具条
（添加×3 / 撤销重做 / 复制粘贴删除，禁用态跟随可操作性）→
Spacer → 「纸张 · 40×30 模切 ▾」（popover 入口，未验证纸张加 ⚠️ 角标）→
设备状态点 + ⚙️（popover 入口）。

### 6.2 设备 popover（原设备卡降级；结构按设计稿定稿）

自上而下（行距 10）：

1. **标题行**「打印机与连接」（13 Semibold）。
2. **状态行**：状态点 8pt（`state.ok` / `text.tertiary` / `state.error` 随状态）
   + 状态文本（12 Medium，已连接 · USB / 连接中… / 未连接 / 失败）
   + 弹性空隙 + 设备号 11 tertiary（即 `deviceSummary`）。
   未连接/失败态时行右端加「扫描 / 重连」pill 按钮（白底 hairline，
   11 Medium accent 文案；失败态额外保留现有 `connectionError` 详情折叠框）。
3. **分隔线**（hairline）。
4. **「连接方式」标签**（11 secondary）+ 原生 segmented（USB / 蓝牙）：
   `bgCanvas` 轨道 radius 6 内衬 2，选中段白色胶囊 radius 4 + 微阴影，
   切换逻辑照搬 `switchMode`，打印/连接中时禁用。
5. **模式相关区域**：
   - USB：说明文案「USB 插入打印机即连；连接失败时点"重连"重试。」
     （11 tertiary，wrap）。
   - 蓝牙：**已保存设备**高亮行（`accentSubtle` 底 radius 6，设备名 12 Medium
     accent + 「上次连接」badge + 行尾「连接」按钮）→ **附近设备**列表
     （每行 32pt：已识别设备 accent 点 + 名称 + 「打印机」accentSubtle badge，
     未识别灰点 + 11 tertiary；对应 `matchesPrinter` / `deviceLabel` 语义）
     + 单连接提示「多数机型仅允许单连接：请先断开手机打印 App 的占用。」

- **降级要求**：连接状态必须同步显示在底栏（§6.4），popover 只承载配置动作。

### 6.3 纸张 popover（结构按设计稿定稿）

自上而下（行距 10，标签列宽 36，校准区标签列宽 56）：

1. **标题行**「纸张与校准」。
2. **尺寸行**：picker 字段（白底 hairline h28 radius 6，值 12 Medium 左对齐
   + 行尾 chevron 12）——`PaperPreset.all` + 自定义；预设联动逻辑（编辑宽高
   即降级为自定义、`paperSelection` Binding 语义）**原样保留**。
3. **未验证警告条**（仅自定义/未验证纸张）：`warn` 12% 透明底 radius 6，
   11pt warn 文案「该尺寸未经真机验证，打印前请用真机校准水平偏移」；
   此时水平偏移数值同用 `warn` 色高亮提示需标定。
4. **宽/高行**：两个并排步进器（各占一半）——白底 hairline 字段内
   「值 12 Medium 左对齐 + 行尾上下双箭头 8×14」（范围 20–48 / 10–100）。
5. **类型行**：picker「模切标签（有间隙）/ 连续纸」。
6. **间隙行**：步进器 1–10 mm step 0.5；**仅模切时显示**（连续纸整行隐藏）。
7. **分隔线** + **「校准与边距（随纸张预设保存）」小节标签**（11 secondary）。
8. **水平偏移**（0–120 点）、**上/下边距**（0–10 mm step 0.5）步进器行——
   **从打印区移入此处**（它们是纸张校准参数，不是打印参数）；
   `leftPadDots` 仍随 preset 应用。

### 6.4 底部状态条（32pt）

`● 设备已连接 · 40×30 模切 · 间隙 3.0mm · 3 个元素` + Spacer + 打印进度
（打印时替换为线性进度条 + "第 n/N 页"）+ 打印结果摘要（成功/失败，5s 后淡出）。

### 6.5 右栏属性检查器（280pt）

无选择：文档概要（纸张、元素数、「适应窗口」按钮、网格开关）。
单选文本：内容多行输入、字号 slider（12–72，snap 2）、粗体、换行宽、
位置 X/Y、与纸张对齐九宫格。
单选二维码/条码：内容输入（条码限字母数字，沿用现有校验）、尺寸/高度
（滑杆 24–160，条码宽度自动推算、不可手调）、位置 X/Y；二维码额外有
**纠错等级** picker 行（L/M/Q/H，默认 M——新增可选参数，字段样式同 §6.3
picker 行；**渲染侧参数，不动协议**）。两种元素与文本一致地显示
「对齐」行（§5.4）。多选：数量 + 对齐分布 + 删除。

> 预览=打印（G4）：`ElementsCanvas` 中文本元素的换行计算改用
> `LabelRenderer.measureText`（CoreText）做断行 + 手动按行绘制，替代
> SwiftUI `Text` 自动换行。该改动只在**预览渲染侧**；打印光栅路径零改动。

### 6.6 画布覆盖层

- 选中框：accent 描边 + 手柄。**现状核实**：现 app 只有右下角一个 12×12
  缩放手柄（`LabelCanvas` liveLayer）。v2 手柄 = 角点 ×4（缩放）+ 边中点 ×4
  （仅文本元素，拖拽调换行宽）；右上角手柄由删除钮替代（见下）。
  多选框：虚线。
- 删除 × 按钮：**中心压在选中框右上角点上**（同现行为
  `.position(x: rect.maxX, y: rect.minY)`，一半露在框外），确认逻辑不变
  （#5/#8 的行为基线）。v2 样式（设计稿定稿）：白底圆钮 + hairline 描边 +
  轻投影 + 红色 ×（`error #FF3B30`），替代现版的蓝 ×。
- 吸附对齐线：`guide.snap` 色，样式不变；吸附开关加到画布右下角浮动小按钮。
- 空画布引导：画布中央灰字「点击上方 ＋ 添加文字 / 二维码 / 条码」。

## 7. 数据模型变更

`LabelElement` 新增（全部带默认值，旧档案 JSON 解码兼容）：

```swift
var hidden: Bool = false          // §5.6 图层显隐
```

`LabelDocument` 不新增字段（纸张/打印参数结构不变）。

明确**不做**：元素旋转、元素分组、颜色（打印机是 1-bit 黑白）。

## 8. 后续候选（本轮明确不做，留档）

- **图片元素**：CGImage → 1-bit 抖动（Floyd–Steinberg）→ 与文本同管线光栅。
  渲染侧改动，协议不动，风险低。
- **模板库**：内置 5–8 个 `LabelDocument` 预设（寄收货、价签、名单条码…），
  顶栏「模板」popover 一键套用（替换 doc、入撤销栈）。
- **文件化文档**（.p1label JSON + NSDocument）与多窗口。
- 元素旋转（打印机与光栅路径均支持任意位图，成本在 UI 与手势）。
- **二维码/条码参数扩展**（全部渲染侧，CoreImage 现成 filter，不动协议）：
  - 条码制式下拉：EAN-13 / UPC-A / CODE39 / ITF（EAN-13 需 12/13 位数字
    + 校验位校验；CODE128 仍为默认）
  - 条码人读文本开关：底部数字行，CoreText 绘制
  - 二维码 quiet zone（留白边距）
  - 明确不做：黑白反转（热敏 1-bit 输出，反打需真机验证才有意义）、
    条码宽度手调（破坏 CODE128 模块比例）。
